# NOVA//X — 3D Brand Site

A creative, mobile-first 3D brand experience for the ASd project.

## Features
- Real-time Three.js/WebGL scene
- Interactive drag/touch orbit controls
- Animated metallic core + orbital rings
- Particle field and cinematic lighting
- Scroll-reactive camera/object motion
- Responsive mobile layout
- No framework or build step required

Open `index.html` in a static web host.
